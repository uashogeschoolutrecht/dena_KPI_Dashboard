D&A Feature Process KPI Dashboard

Inzicht in het Feature-proces van het Data & Analytics team in Azure DevOps.

Over dit project

Dit dashboard analyseert doorlooptijden en effort van Features binnen Azure DevOps, van de retrospective op 20 februari 2025 tot nu. Het combineert wachttijd (Geprioriteerd → In progress) en doorlooptijd (In progress → Done) per domein en effort-categorie.
